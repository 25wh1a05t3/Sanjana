📖 Quick Study Notes

Click a topic to reveal its notes.

What is HTML?

HTML stands for HyperText Markup Language. It structures web pages using elements such as headings, paragraphs, images and links.

What is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance of web pages, including colours, layouts, spacing and fonts.

What is a computer network?

A computer network connects devices so they can exchange information and share resources.

What is an algorithm?

An algorithm is a finite sequence of clear steps used to solve a problem or complete a task.

"Great things are done by a series of small things brought together."

Try the 25-minute focus method

1. Choose one task.

2. Study for 25 minutes without distractions.

3. Take a 5-minute break.

4. Repeat when ready.

This is a suggested routine, not an automatic timer. You can use a clock or a separate timer to track time.
